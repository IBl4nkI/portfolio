SariSite: Online Ordering for Local Sari-Sari Stores

Description

SariSite is an online browsing and ordering system for subdivision sari-sari stores, designed to simplify shopping and order management.

Technologies and Components Used

  • Flutter and Dart for the interface
  • Node.js and Express.js for backend services
  • MongoDB for data storage
  • Firebase Authentication with Google Sign-In
  • Bruno for API testing and GitHub for version control
  • Agile sprint-based development

Objectives

  • Make product browsing and ordering more convenient for subdivision residents.
  • Provide a clear, user-friendly experience for customers and store owners.
  • Support order and delivery management and assess the system against customer and owner needs.

My Role and Contribution

  • Head Project Manager: Led sprint planning and team coordination, tracked timelines and user requirements, and brought close attention to research details.
  • Frontend and Backend Developer: Contributed substantially to both sides of the application.

Finished Output/Result

The project includes frontend and backend repositories. Research defined key ordering and store-management requirements; customers rated online sari-sari store ordering 3.68 (“Strongly Agree”).

  • Frontend: Sari-Sari Store Frontend
  • Backend: Sari-Sari Store Backend
